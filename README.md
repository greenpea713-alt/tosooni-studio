# 토순이 친구 스튜디오

https://tosooni-studio.vercel.app

영상을 올리면 '토순이 친구' 편집 규칙대로 한 편씩 깔끔하게 만들어 주는 웹앱이에요.
`main`에 푸시하면 Vercel이 자동으로 다시 배포해요.

## 편집 규칙 (앱이 자동으로 지키는 것)

이 규칙은 `app.js` 맨 위의 `RULE`과 `outputsOf()`, `buildPlan()`에 그대로 들어 있어요. 규칙을 바꾸면 코드와 이 문서를 같이 고쳐 주세요.

1. **합치지 않기.** 원본 영상은 여러 개를 올려도 각각 처음부터 끝까지 따로 편집해요.
2. **규격**
   - 세로 영상(3분 이하) → 1080×1920 30fps 쇼츠
   - 가로 영상, 그리고 3분이 넘는 영상 → 1920×1080 일반 영상 (3분 넘는 세로 영상은 가운데에 두고 양옆은 아이보리)
   - 가로 영상 중 토끼가 잘리지 않는 것만, 사용자가 고르면 세로 크롭 쇼츠를 한 편 더 (크롭 위치는 직접 고름)
3. **오디오**
   - 바람 클리핑 복원(adeclip) → 150Hz 이하 컷(highpass) → 노이즈 제거(afftdn)
   - 말소리 없이 마이크 잡음(히스)만 있는 영상은 원음 음소거 (노이즈 제거로 8dB 이상 줄거나 원래 -50 LUFS보다 작으면 잡음으로 판단)
   - 전체 음량 -14 LUFS (장면별로 맞춘 뒤 리미터)
   - **BGM은 넣지 않아요.** 사용자가 직접 넣어요.
4. **자막**은 반전이 있는 영상의 도입부에만, 위쪽에 작게(3.5초). 나머지는 자막 없이.
5. **디자인**
   - 폰트 Noto Sans KR. 본편은 깨끗하게(블러, 큰 장식 없음), 작은 TOSOONI 로고와 은은한 웜톤만.
   - 가로 영상: 오프닝(기본 4초 인트로) → (타이틀 카드) → 본편이 아이보리에서 0.35초 페이드인 → 끝 0.5초 아이보리 페이드아웃
   - 쇼츠: 오프닝 → (타이틀 카드) → 본편이 아이보리에서 페이드인 → 0.3초 교차로 토순이 엔딩
   - 오프닝은 가로·쇼츠 모두 맨 앞에 붙어요(쇼츠에서 가로 오프닝은 가운데에 두고 위아래를 종이색으로 채움).
   - 테마는 클래식(아이보리·골드, 기본), 가을(크림 종이 + 단풍·은행잎 페이퍼컷, 낙엽 전환), 보태니컬(초록 타이틀, 잎 전환) 중 선택.

## 파일
- `index.html`, `style.css`, `app.js`: 앱 전체 (빌드 과정 없음)
- `assets/`: 오프닝, 초록 타이틀 카드, 테두리, 잎 전환(블루스크린), 쇼츠 엔딩
- `vendor/ffmpeg/`: 소리 다듬기와 형식 변환용 ffmpeg.wasm (필요할 때만 불러옴)

모든 처리는 브라우저 안에서만 해요. 영상이 서버로 올라가지 않아요.
