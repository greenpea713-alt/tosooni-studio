# 토순이 친구 스튜디오

https://tosooni-studio.vercel.app

영상을 올리면 '토순이 친구' 편집 규칙대로 한 편씩 깔끔하게 만들어 주는 웹앱이에요.
`main`에 푸시하면 Vercel이 자동으로 다시 배포해요.

## 편집 규칙 (앱이 자동으로 지키는 것)

이 규칙은 `app.js` 맨 위의 `RULE`과 `outputsOf()`, `buildPlan()`에 그대로 들어 있어요. 규칙을 바꾸면 코드와 이 문서를 같이 고쳐 주세요.

1. **여러 영상: 이어서 한 편 / 각각 한 편.** 두 개 이상 올리면 01 칸 위에 `자동 · 각각 한 편 · 이어서 한 편`이 떠요. 기본은 '자동'이고, 앱이 앞 영상 끝 장면과 다음 영상 첫 장면의 색감·장면 비슷함(62% 이상), 파일 시각 차이(2시간 안), 가로·세로가 같은지만 보고 추천해요. **이야기 내용까지 이해한 판단은 아니에요.** 추천 이유는 화면에 그대로 보이고, 버튼 하나로 바꿀 수 있어요. 이어 붙이면 올린 순서대로 한 편이 되고 사이는 0.25초 아이보리로 살짝 끊어요. (예전 '절대 합치지 않기' 규칙을 이걸로 바꿨어요.)
1-1. **지루한 대기 구간 빨리감기 (시험 기능).** 올리면 영상을 소리 없이 빠르게 훑어서, 화면이 거의 안 움직이는 구간이 6초 넘게 이어질 때만 ×4(20초 넘으면 ×8) 빨리감기를 *제안*해요. 그 구간의 앞 1.5초·뒤 1초는 원래 속도로 남겨서 움직이기 직전·직후 행동은 그대로 보여요. 빨리감는 동안 소리는 30%로 줄여요. 움직임이 적다는 것만으로 지루하다고 단정하지 않도록 기준을 보수적으로 잡았고, 편집 화면 '빨리감기' 줄에서 구간마다 배속 바꾸기·지우기·직접 지정(여기부터/여기까지)·'모두 원래 속도'로 되돌릴 수 있어요.
2. **규격**
   - 세로 영상(3분 이하) → 1080×1920 30fps 쇼츠
   - 가로 영상, 그리고 3분이 넘는 영상 → 1920×1080 일반 영상 (3분 넘는 세로 영상은 가운데에 두고 양옆은 아이보리)
   - 가로 영상 중 토끼가 잘리지 않는 것만, 사용자가 고르면 세로 크롭 쇼츠를 한 편 더 (크롭 위치는 직접 고름)
3. **오디오**
   - 바람 클리핑 복원(adeclip) → 150Hz 이하 컷(highpass) → 노이즈 제거(afftdn)
   - 말소리 없이 마이크 잡음(히스)만 있는 영상은 원음 음소거 (노이즈 제거로 8dB 이상 줄거나 원래 -50 LUFS보다 작으면 잡음으로 판단)
   - 전체 음량 -14 LUFS (장면별로 맞춘 뒤 리미터)
   - **BGM은 넣지 않아요.** 사용자가 직접 넣어요.
4. **자막**은 반전이 있는 영상의 도입부에만, 위쪽에 작게(3.5초). 나머지는 자막 없이.
5. **디자인**
   - 폰트 Noto Sans KR. 본편은 깨끗하게(블러, 큰 장식 없음), 작은 TOSOONI 로고와 은은한 웜톤만.
   - **여백과 전환**: 화면이 계속 꽉 차 보이지 않도록 여백을 넉넉하게 둔다. 중간 화면 전환과 타이틀 카드에서는 가운데 작은 **동그란 토순이 아이콘** 포인트만 가볍게 띄우는 미니멀 스타일을 지향한다.
   - **배경은 매끈한 단색으로**: 타이틀 카드와 전환 화면 배경에 거친 종이 질감 노이즈나 미세 얼룩을 넣지 않는다. 영상 압축을 거치면 배경이 우글우글하고 지저분해 보여서, 매끈하고 깨끗한 단색 배경을 기본으로 유지한다. (`paperTexture()`는 단색 채우기만 해요.)
   - 클래식 테마의 **전환 카드**: 매끈한 아이보리 화면 가운데에 작은 동그란 토순이 아이콘만 1.4초 띄운다. 타이틀이 없을 때 오프닝과 본편 사이, 그리고 가로 영상의 끝에 들어간다.
   - **시작 인트로와 끝 엔딩은 따로 고른다.** 기본 시작은 **사진 인트로 1.1초**(아이보리 위 동그란 토순이 실제 사진 `assets/tosooni-face-photo.jpg` + 얇은 골드 테두리 + TOSOONI). 다른 선택은 종이 인트로(2.4초), 없음, 그리고 '다른 오프닝' 안의 4초 인트로·공식 오프닝 11.7초·보태니컬. 사진·종이 인트로를 고르면 뒤의 아이콘 쉼표 카드는 넣지 않는다. 공식 오프닝 파일은 바꾸지 않는다.
   - 끝 엔딩 기본은 **없음**(아이보리로 부드럽게 페이드아웃). 쇼츠에서 원하면 '토순이 엔딩'. 인트로 없이 엔딩만 붙는 일이 없게 기본값을 맞췄다.
   - 제목은 '오늘은'으로 고정하지 않고 자유롭게 한 줄로 쓴다. 예) `오늘은 산책하러 가는 날`, `강아지를 만난 토끼`.
   - 순서: 시작 인트로(기본 사진 1.1초) → (타이틀 카드) → 본편이 아이보리에서 페이드인 → 끝 아이보리 페이드아웃 → (엔딩을 골랐을 때만: 쇼츠는 토순이 엔딩, 가로는 아이콘 카드)
   - 오프닝은 가로·쇼츠 모두 맨 앞에 붙어요(쇼츠에서 가로 오프닝은 가운데에 두고 위아래를 종이색으로 채움).
   - 테마는 클래식(아이보리·골드, 기본), 가을(크림 종이 + 단풍·은행잎 페이퍼컷, 낙엽 전환), 보태니컬(초록 타이틀, 잎 전환) 중 선택. 테마가 달라도 배경은 매끈한 단색이 기본이다.
   - **카드 쇼츠(선택, 기본 꺼짐)**: 세로 쇼츠를 크림 카드(`#FAF6EE`)에 담는 레이아웃. 위에서부터 동그란 프로필(기본 토순이 아이콘 / 내 사진 / 없음) → 제목 → 영상(원본 비율 그대로, 폭 42~86%) → 자막 → 하단 TOSOONI. 바깥 라운드 테두리·그림자 박스는 켜고 끌 수 있고, 프로필을 끄면 제목이 위로 올라온다. 켜면 별도의 타이틀 카드·아이콘 카드 없이 카드 한 장으로 이어지고, 제목·자막은 미리보기에서 글자를 눌러 그 자리에서 고친다(프리뷰·내보내기 동시 반영). 카드에서는 영상 비율을 절대 늘리지 않고, 자리가 모자라면 영상 폭을 줄인다.
6. **품질 확인은 유튜브 실제 업로드 기준**
   - 모든 편집 결과물은 최종 유튜브 업로드 규격(1080p)과, 유튜브가 다시 인코딩·압축한 뒤의 화질을 기준으로 확인한다.
   - 압축 후에도 깨짐, 뭉개짐, 비율 왜곡(눌림·찌그러짐)이 없어야 한다. 미리보기 화면에서만 깨끗하면 통과가 아니다.
7. **비율은 절대 바꾸지 않는다 (예외 없음)**
   - 원본을 가로나 세로로 늘리거나 누르지 않는다. 항상 원본 비율 그대로 **맞춰 넣거나(빈 곳은 매끈한 아이보리)** **잘라 낸다(크롭)**.
   - 결과물은 1920×1080 또는 1080×1920만 만든다. 1280×720 같은 다른 크기로 다시 인코딩하지 않는다.
   - 앱은 원본 비율을 그대로 유지해 그린다(`drawVideo`는 한 배율로만 확대·축소). 픽셀 비율(SAR)도 반영한다.
   - **휴대폰 회전 메타데이터(`displaymatrix`)를 지킨다**: 스마트폰 원본은 컨테이너(파일) 크기가 `1280×720`처럼 가로여도 회전 정보 때문에 실제로 보이는 화면은 세로 `720×1280`인 경우가 많다. 컨테이너 숫자만 보고 가로·세로를 판단하지 않고, 회전을 반영한 **실제 디코드 화면 크기**로 규격을 정한다.
   - 가로(1920×1080) 결과물에 세로 클립을 넣거나 세로·가로 영상을 오갈 때도 비율 유지 없이 강제로 늘리지 않는다. `force_original_aspect_ratio=decrease`로 비율을 지킨 채 맞추고, 남는 곳은 매끈한 단색(아이보리) 여백으로 채운다.
   - 앱이 만든 파일을 다른 도구로 다시 인코딩·리사이즈하지 않는다. 그대로 내려받아 올린다.
8. **완성본은 실제 프레임을 눈으로 검수한다**
   - 편집이 끝나면 결과물에서 **실제 프레임을 꺼내 직접 눈으로** 확인한다. 타임라인 미리보기나 섬네일만 보고 넘어가지 않는다.
   - 토끼가 옆으로 늘어나거나 위아래로 눌린 비율 왜곡(찌그러짐)이 없는지, 회전이 잘못 적용돼 화면이 눕거나 뒤집히지 않았는지 본다. 세로 클립을 가로 결과물에 넣은 경우(또는 그 반대)는 특히 꼼꼼히 본다.
   - 이 확인을 마친 뒤에만 전달하거나 업로드한다. 한 프레임이라도 이상하면 그대로 올리지 않고 원인을 찾아 다시 만든다.

## 화면 쓰는 법
- 배치: 밝은 웜그레이 바탕(#F4F3F0)에 흰 칸, 글자는 차콜. 넓은 화면(1100px 이상)에서는 왼쪽에 영상 목록·스타일, 오른쪽에 큰 미리보기. 휴대폰에서는 올리기 → 미리보기·고치기 → 스타일 순서.
- **01 영상 올리기**: 올리자마자 목록에 뜨고, 다 열린 영상부터 바로 만들 수 있어요(아이폰 HEVC 변환이나 소리 다듬기가 끝나길 기다리지 않음). 영상 하나가 25초 안에 안 열리면 그 영상만 '실패'로 표시되고 나머지는 계속 돼요. 카드를 누르면 그 영상이 편집 화면에 열려요. 제목·자막은 카드가 아니라 편집 화면에서 고쳐요.
- 만드는 중에 **멈추고 고치기**를 누르면 바로 멈추고 편집 화면이 다시 열려요. 문제가 생기면 이유를 띄우고 버튼은 다시 쓸 수 있어요.
- **02 스타일**: 테마·시작 인트로·끝 엔딩 버튼마다 실제 모습 썸네일이 있어요. 누르면 그 썸네일 안(과 03 미리보기)에서 그 부분만 바로 재생돼요.
- **03 미리보기 · 고치기 · 만들기**: 영상을 올리면 바로 편집 화면이 떠요.
  - 미리보기 바로 위의 '시작/끝' 칩으로 인트로·엔딩을 바로 바꿔요.
  - 타임라인: 오프닝·제목·본편(여러 개면 본편 1, 2…)·마무리가 띠로 보이고, 빨리감기 구간은 빗금과 ×배속으로 보여요, 끌어서 원하는 초로 가요. 스페이스 재생·멈춤, ← → 1초(Shift는 1프레임).
  - 제목·자막을 고치면 그 장면으로 가서 바로 보여 줘요. 자막은 '지금 위치에서 시작'과 길이(초)로 시점을 정해요(타임라인 위 분홍 띠).
  - 본편 다듬기: 필름 띠의 양쪽 손잡이로 앞뒤를 잘라요(사람 얼굴 나오는 구간 빼기 등). '지금 위치를 시작/끝으로'도 돼요.
  - '이 편 만들기 / 다시 만들기'로 그 영상만 다시 만들고, 결과 목록의 같은 파일을 새것으로 바꿔요. 결과 목록의 '고치기'를 누르면 그 편이 편집 화면에 열려요.

## 파일
- `index.html`, `style.css`, `app.js`: 앱 전체 (빌드 과정 없음)
- `studio-ui.js`: 카드 쇼츠 설정과 미리보기 위 제목·자막 바로 고치기. (맨 위 프리셋·말풍선은 뺐어요. 가로·세로는 앱이 알아서 정해요.) `app.js`는 건드리지 않고 이미 있는 버튼을 눌러 주기만 해요. (당근 커서는 `style.css` 안의 SVG 데이터 URL, 어디서나 당근)
- `assets/`: 오프닝, 초록 타이틀 카드, 테두리, 잎 전환(블루스크린), 쇼츠 엔딩
- `vendor/ffmpeg/`: 소리 다듬기와 형식 변환용 ffmpeg.wasm (필요할 때만 불러옴)

모든 처리는 브라우저 안에서만 해요. 영상이 서버로 올라가지 않아요. 그래서 만드는 데 영상 길이만큼 걸리고 탭을 띄워 둬야 해요. 서버 렌더링(Firebase + Cloud Run)은 검토만 했고 아직 붙이지 않았어요(구글 클라우드 접근·결제 허락이 있어야 해요).

## 피클(개인 AI 비서)과 같이 쓰기
`pickle.md`에 피클이 이 앱을 브라우저로 직접 쓰면서 사람처럼 검토할 부분(타이틀, 반전 자막, 크롭 쇼츠 여부·위치, 소리 판단)을 정리해 뒀어요. 입력칸과 버튼에는 "1번 영상 …" 같은 이름표(aria-label)가 붙어 있어요. 규칙을 바꾸면 `pickle.md`도 같이 고쳐 주세요.

제목·설명·도입부 자막의 말투는 과장되거나 작위적인 유튜브 어그로 톤을 피하고, 집사가 토순이에게 말 거는 듯한 담담하고 귀여운 일상 말투로 써요. 기준 예시는 제목 `강아지를 만난 토끼`, 설명 `강아지가 너무 반가워하는데… 토끼는 생각보다 너무 담담하게,, 가만히있었다ㅠㅋㅋ 안무서웠니` 정도의 결이에요.
