# 토순이 친구 스튜디오

영상을 올리면 '토순이 친구' 브랜드 템플릿이 자동으로 입혀지는 웹앱이에요.

오프닝 → 타이틀 카드("오늘은 ○○하는 날") → 본편(보태니컬 테두리) → 잎 전환 → 엔딩

- 첫 영상의 방향을 보고 가로(1920×1080) / 세로 쇼츠(1080×1920)를 자동으로 골라요.
- 여러 영상을 올리면 순서대로 이어 붙이고 사이에 잎 전환을 넣어요.
- 음량은 장면마다 -14 LUFS에 맞추고 리미터로 피크를 눌러요(근사치).
- 모든 처리는 브라우저 안에서만 해요. 영상이 서버로 올라가지 않아요.
- 결과는 브라우저가 지원하면 mp4, 아니면 webm으로 저장돼요.

## 파일
- `index.html`, `style.css`, `app.js`: 앱 전체 (빌드 과정 없음)
- `assets/`: 오프닝, 타이틀 카드(빈 버전), 테두리 PNG, 블루스크린 전환, 쇼츠 엔딩

## 배포
Vercel에서 이 저장소를 Import 하면 끝. `main`에 푸시할 때마다 자동으로 다시 배포돼요.
